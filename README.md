# LINE Vault (LINE 金庫)

> **Windows 11 原生 LINE 本地對話與防過期媒體管理中心**  
> 具備 E2EE 端對端加密媒體解析、快取即時防過期永久留存、FTS5 全文檢索與 AI 智慧對話摘要與行動建議。

---

## 🎯 痛點與解決方案

LINE 電腦版使用者最常面臨的致命痛點：
1. **「檔案過期無法讀取」**：LINE 伺服器上的照片、影片與文件有嚴格的暫存期限，一旦超期便永遠消失。
2. **全文檢索緩慢與雜亂**：跨群組、跨聊天室難以進行精準關鍵字與日期篩選。
3. **重要工作待辦遺漏**：專案群組中客戶隨口交代的需求、截止日或報價未被結構化提取。

**LINE Vault** 在本地自動對接 LINE 快取目錄，在檔案過期前利用端對端加密（E2EE）密鑰還原真實二進位檔案，並將其永久保存於使用者的安全金庫（Vault）中，同時提供極簡流暢的繁體中文 Web UI 與強大的 CLI 介面。


## ✨ 核心特性

- **🛡️ 防過期永久備份**：依據 LINE Encryption Overview v2.2 規範，驗證 32 位元組 HMAC-SHA256 標籤並還原 AES-256-CTR 密文，確保相片、影片與重要合約永不過期。
- **🔍 本地 FTS5 毫秒檢索**：支援複合條件查詢（聊天室、關鍵字、媒體類型、起訖日期），支援即時高亮標記。
- **🤖 智慧對話分析**：
  - **對話重點摘要**：自動歸納參與者發言主題與脈絡。
  - **行動清單提取**：自動辨識期限（如「週五前」、「明天」）、金流（「報價」、「發票」）與待辦。
  - **檔案巡檢狀態**：即時標示已永久存檔、縮圖暫存中或亟需快取之檔案。
  - **一鍵建議回覆**：針對最後對話情境提供 3 組不同語氣的繁體中文回覆草稿，點擊即可複製。
- **🌐 零外部 Web 框架依賴**：內建基於 Python 標準庫 `http.server.ThreadingHTTPServer` 的高效 REST API 與原生 Dark Mode 繁體中文 Web 介面。
- **🔒 100% 本地隱私保障**：金庫資料庫與解密檔案完整保存在使用者本機磁碟，完全無外部雲端上傳或遙測。

## 🚀 快速開始

### 1. 系統需求
- **作業系統**：Windows 11 原生環境（或 Windows 10）
- **Python 版本**：Python 3.10 或更新版本

### 2. 安裝方式

```powershell
# 切換至專案根目錄
cd C:\GitHub\line-vault

# 安裝依賴（僅需 cryptography）
pip install -r requirements.txt
```

### 3. 一鍵啟動 Web 管理介面

您可直接雙擊執行 `start_line_vault.bat`，或在終端機輸入：

```powershell
python -m line_vault web --port 8765
```

伺服器將在 `http://127.0.0.1:8765` 啟動並自動開啟瀏覽器。

## 💻 命令列操作 (CLI)

LINE Vault 亦提供完整直覺的命令列工具：

```powershell
# 1. 檢視金庫統計數據 (聊天室數、訊息總量、永久媒體檔案與佔用容量)
python -m line_vault stats

# 2. 搜尋訊息與重要對話
python -m line_vault search "報價單"

# 3. 執行特定聊天室之 AI 智慧分析與行動提取
python -m line_vault analyze --chat-id "c_project_alpha"

# 4. 分析所有已啟用監控的聊天室
python -m line_vault analyze --all

# 5. 載入並重設內建繁體中文範例資料
python -m line_vault seed
```

## 🔐 E2EE 媒體解密演算法規格

根據 LINE 官方 E2EE 規範，媒體加密檔案的結構如下：

```
+----------------------------------------------+---------------------------+
| 密文主體 (Ciphertext, AES-256-CTR)           | 驗證標籤 (HMAC-SHA256, 32B)|
+----------------------------------------------+---------------------------+
|<----------------- (N - 32) Bytes ------------>|<-------- 32 Bytes ------->|
```

1. **金鑰衍生 (HKDF-SHA256)**：
   - 輸入：32 位元組 Key Material（Base64 編碼）
   - Salt：`None`
   - Info：`b'FileEncryption'`
   - 輸出：76 位元組位元流
   - 分割配發：
     - `enc_key` = 前 32 位元組（AES-256）
     - `mac_key` = 次 32 位元組（HMAC-SHA256）
     - `iv` = 後 12 位元組 + `b'\x00\x00\x00\x00'`（16 位元組 CTR IV）
2. **完整性校驗**：計算 `HMAC-SHA256(mac_key, ciphertext)`，使用常數時間比對（`compare_digest`）確認與最後 32 位元組完全相符。
3. **還原解密**：使用 `enc_key` 與 `iv` 進行 AES-256-CTR 解密還原二進位資料。
4. **格式探測**：分析解密後二進位資料的前導 Magic Bytes，自動還原副檔名（`.png`, `.jpg`, `.mp4`, `.pdf`, `.zip` 等）。
