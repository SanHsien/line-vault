## 詳細里程碑說明

### Phase 1: 核心加密金庫與毫秒檢索 (Core Vault & FTS5) — `[x] 已完成`
- [x] LINE E2EE（Letter Sealing）AES-256-CBC 媒體解密引擎與 SHA-256 完整性驗證。
- [x] 多媒體真實檔案格式探測（Magic Bytes Sniffer：JPEG, PNG, GIF, MP4, PDF, ZIP 等）。
- [x] SQLite WAL 高並發架構，支援 FTS5 全文檢索與快速倒排索引。
- [x] 本地快取檔案指紋比對與自動解密金庫留存機制。

### Phase 2: 純 GUI 工作台與 Windows 桌面整合 (Modern Desktop GUI) — `[x] 已完成`
- [x] 零前端構建依賴之原生 3 欄式深色主題工作台（聊天室清單、對話與媒體櫃、AI 智慧分析面版）。
- [x] Windows 11 原生獨立視窗啟動（`start_line_vault.bat` 雙擊無黑視窗啟動，Microsoft Edge / Chrome `--app` 模式）。
- [x] 多媒體相片牆、影片庫與檔案櫃視覺化瀏覽，支援本地原檔即時下載。
- [x] 快速日期區間篩選與全文即時搜尋高亮。

### Phase 3: AI 智慧分析與情境回覆建議 (Smart Insights & Replies) — `[x] 已完成`
- [x] 本地規則與 AI 分析引擎，萃取專案交付期限、金流報價、關鍵提問與指派任務。
- [x] 聊天室附件健康度檢視（已永久金庫保存、縮圖快取中、需快取防過期）。
- [x] 依據對話情境生成 3 種不同語氣（商務專業、積極溝通、細節嚴謹等）的智慧回覆草稿與一鍵複製。
- [x] 雙語 AI 分析支援（繁體中文 `zh-TW` 與英文 `en`）。

### Phase 4: 訊息收藏星號與待辦事項核銷閉環 (Bookmarks & Action Tracking) — `[x] 已完成`
- [x] 訊息層級收藏功能（⭐ 點擊切換收藏狀態，持久化保存至資料庫）。
- [x] 獨立「收藏訊息」專屬導覽分頁，快速彙整跨時間關鍵訊息。
- [x] AI 待辦清單支援即時勾選核銷（✅ Checkbox），已完成事項自動劃記並自儀表板待辦統計扣除。

### Phase 5: 一鍵報告匯出與文字對話歷史匯入 (Report Export & Chat Import) — `[x] 已完成`
- [x] 一鍵匯出對話與 AI 分析報告（支援結構化 Markdown 與完整資料 JSON 格式）。
- [x] GUI 介面直接上傳與解析 LINE 桌面版／手機版匯出之 `.txt` 對話紀錄檔案。
- [x] 匯入後自動建立聊天室並即時啟動 AI 分析與待辦清單建立。
- [x] 完整中英雙語 GUI 切換（繁中 / English 一鍵動態切換）。

### Phase 6: 自動更新巡檢、貼圖/媒體子資料夾分類與全量同步 — `[x] 已完成`
- [x] 訊息貼圖自動下載保存至本地金庫（優先檢查本機 LINE 快取，無快取則自官方 CDN 下載 PNG）。
- [x] 依「聊天室名稱」自動建立獨立子資料夾存放媒體與貼圖，自訂存放根目錄。
- [x] 可自由勾選自動下載項目（貼圖、圖片、影片、檔案與文件）。
- [x] 全時間範圍無上限同步與 AI 分析（解除原本 14 天與 300 則限制，日期區間僅作顯示篩選）。
- [x] 支援個人、群組、社群（OpenChat / Community）分類篩選與圖示。
- [x] 後台 daemon 自動更新排程器（預設每 5 分鐘自動同步更新）。
- [x] 移除 About 視窗多餘之跳轉按鈕，介面簡潔化。

### Phase 7: 雲端外送與雙軌自動歸檔架構 (借鏡社群最佳實踐) — `[ ] 規劃中`
- [ ] **Google Drive / Sheets 雲端外送鏡像**：借鏡社群主流工作流程，將本地金庫歸檔之檔案與關鍵對話摘要選擇性外送至指定的雲端 Google Drive 與 Google Sheets。
- [ ] **Gemini 視覺模型 (Multimodal) 與 Function Calling**：針對已下載的圖片、發票、合約文件，串接 Gemini 視覺模型進行自動欄位結構化與記帳分類。

---

## 未來願景 (Future Visions)

- [ ] **離線語音轉文字**：整合本機輕量 Whisper 模型，點擊語音訊息即可離線轉譯繁中字幕。
- [ ] **外部自訂 LLM 串接**：支援自訂 Ollama、OpenAI 相容端點進行更深入的多輪對話洞察。
- [ ] **自動排程備份**：Windows 工作排程器整合，在後台定期巡檢並對新增檔案進行增量金庫封存。
