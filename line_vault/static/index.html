📖 LINE Vault 快速開始與功能測試指南

步驟 1

✨ 一鍵載入範例資料（最快體驗完整功能）

首次測試無須準備任何檔案！點擊下方或右上角「✨ 載入範例資料」，系統將立即建立 4 個擬真聊天室（含加密相片、MP4 影片、PDF 合約、ZIP 附件），並自動完成本地解密歸檔與 AI 智慧分析。

步驟 2

🔄 匯入您真實的 Windows 11 LINE 資料（3 種方式任選）

點擊頂部「⚙️ 金庫與同步設定」可隨時執行：

  • 🔄 掃描本機 LINE 快取資料夾：自動掃描 %LOCALAPPDATA%\LINE\Data，透過 Magic Bytes 自動辨識並解密還原相片、影片與文件，永久防過期保存。
  • 📄 匯入 LINE 文字對話紀錄 (.txt)：將 LINE 匯出的 .txt 聊天備份直接選檔匯入，立即轉為可搜尋對話並產生 AI 摘要。
  • 🔐 同步 LINE 加密資料庫 (MCP)：搭配 line-desktop-mcp 引擎同步本機對話紀錄。
步驟 3

🛡️ 體驗防過期媒體庫、訊息收藏與 AI 待辦追蹤

  • 切換五大分頁：在中央面板上方切換「💬 對話紀錄」、「⭐ 收藏訊息」、「🖼️ 相片牆」、「🎬 影片庫」、「📁 檔案櫃」。
  • 收藏與全域搜尋：點擊對話氣泡旁的「☆」加入收藏；在頂部搜尋框輸入關鍵字（如「合約」、「報價」）體驗 FTS5 毫秒級跨聊天室檢索。
  • AI 待辦勾選與報告匯出：在右側面板直接勾選「✅ 自動提取待辦」，或點擊「📋 複製回覆」、「📥 匯出報告」下載 Markdown 總結報告。
